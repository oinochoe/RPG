Fantasy Inventory UI Pack

Description:
A clean and stylized fantasy inventory user interface pack generated with Processing. 
Designed for easy integration into game engines and UI systems.

Contents:
- 7 slot states (normal, hover, selected, locked, rare, epic, legendary)
- 1 inventory grid (6x4)
- 1 equipment layout
- 1 inventory panel
- High-quality PNG files
- Processing source file (.pde)

Features:
- Consistent color palette
- Ready-to-use UI elements
- Easily customizable via source code
- Suitable for RPG, fantasy, and adventure games

Formats:
- PNG (with transparency)
- Processing (.pde source)

Compatible with:
- Unity
- Godot
- Love2D
- Any engine supporting PNG UI assets
