# Phone performance pass (feat/perf)

No device profiler was available; every change is based on well-known three.js cost behavior. No numbers are claimed.

1. Projectile pointLights removed (Projectile.tsx): replaced with an additive, depthWrite=false, toneMapped=false halo sphere. Removes light-count changes on each bolt/skill-arrow cast, which changed the program key of every lit material and caused recompiles. Adds 1 cheap transparent draw per projectile. Desktop look: glow no longer lights nearby surfaces (slight visual change, unavoidable) but halo stays. Risk: glow less "real". Guard test noDynamicLights.test.ts covers Projectile, skillFxParts, SkillFxRoot, HitSparks, DamageNumbers, ItemDropMesh.
   Audit: Village, CaveEntrance, AncientRuins lights are mounted in Ground (always present in the field); Dungeon torches/portal mount with the dungeon area. Count changes only on area transitions (one-time), left unchanged.
2. Touch devices skip EffectComposer (Scene.tsx); a CSS radial-gradient vignette (GamePage.tsx, fixed, pointer-events none, z-index 0 before the HUD) replaces it. Removes the offscreen render target and the mip-blur bloom + vignette full-screen passes. Desktop unchanged. Risk: no bloom on phones (intensity was only 0.15); vignette approximated.
3. shadowMapSizeFor(isTouch) in LightRig.tsx: 1024 on touch (4x fewer shadow texels, 4 MB -> 1 MB-ish depth map memory/fill), 2048 desktop. Unit test added. Risk: slightly blockier shadows on phones. Changing size on pointer-type change re-allocates the map (rare).
4. SkillFxWarmup.tsx + warmSkillFxTextures(): texture warm-up only (builds crescent and fade canvas textures at scene mount and uploads via gl.initTexture). Shader variant pre-compile NOT implemented: gl.compile skips invisible objects and an off-screen instance could not be verified as correct without running. Part cap untouched.

Not changed (candidates): per-monster AnimationMixers; outline pass doubling draw calls; GamePage chunk ~1.2 MB (manualChunks); fog/dpr tuning; instancing for trees/props; static torch lights could become emissive fakes to cut per-fragment light cost in dungeons.

Verification: tsc -b clean, vitest all passing (62 files), npm run build OK, mockServiceWorker.js restored.
